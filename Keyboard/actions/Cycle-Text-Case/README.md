# Cycle-Text-Case

**Shortcut:** `Ctrl+U`  
**Type:** Built-in  
**Entry point:** [`Cycle-Text-Case.ahk`](Cycle-Text-Case.ahk) (AutoHotkey v1.1)

## What it does

Cycle selected text through UPPERCASE, lowercase and Capitalised Words. Leave selections without letters unchanged.

## Dependencies

An editable text field that supports standard selection and paste.

## Test

In Notepad select `hello world`, press Ctrl+U repeatedly, and verify the case sequence and clipboard restoration.

## Editing

Edit [`Cycle-Text-Case.ahk`](Cycle-Text-Case.ahk) to change this action only. Shared utilities are in [`../../src/Keyboard-Setup-Action-Common.ahk`](../../src/Keyboard-Setup-Action-Common.ahk). Changes to this action file take effect the next time its shortcut runs; editing the shortcut registration itself requires a resident restart. A configured `FILE TO RUN` override can take priority over this file.

See the [project README](../../README.md) and [shortcut reference](../../docs/SHORTCUTS.md).
